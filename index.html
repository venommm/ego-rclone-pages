EGOs Server Backup

This project documents a private backup system operated by its owner. It uses rclone to transfer backup archives between a privately managed server and the owner's Google Drive account.

Purpose

The OAuth client is used for personal server backup and recovery. It is not a public file hosting service and is not intended for use by other users.

Data handling

rclone accesses Google Drive files according to the permissions granted by the account owner. OAuth credentials and tokens are managed by rclone on the owner's server. Backup archives are transferred to the owner's Google Drive for backup and recovery.

Privacy

Read the Privacy Policy for details about Google account data access, storage, and use.
